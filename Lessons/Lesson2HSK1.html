Second lesson HSK 1: SVO order

Chinese basic grammatical order:

Chinese basic grammatical order is SVO, wich means each phrase is structured like this:

Subject + Verb + Object

So how does an SVO phrase looks like?

Let's see an example:

我吃苹果 (wǒ chī píngguǒ) (I eat an apple), you already learned this phrase in the last lesson

In this case 我 is the subject, 吃 the verb and 苹果 the object

我 + 吃 + 苹果 = 我吃苹果 (S + V + O = CoolPhrase)

Let's try with another example, learn these new words:

Hanzi Pinyin English
水 shuǐ Water
茶 chá Tea
喝 hē To drink
比萨 bǐsà Pizza (yum)

New examples:

let's see it working in some examples:

我喝茶 (Wǒ hē chá) I drink tea

我喝水 (Wǒ hē shuǐ) I drink water

我吃比萨 (Wǒ chī bǐsà) I eat pizza

Notice the pattern?
