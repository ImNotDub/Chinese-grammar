Hello this is my own website to learn Chinese grammar, please expect changes as I update the site while I learn

Why did I decide to create this site?

I noticed that there aren't a lot of clear Chinese grammar sites (at least from what I've seen.) a lot of them have an explanation way too long or too short. or other times they lack a clear order to learn the grammar so you don't know what to learn first.

so I decided, why shouldn't I create my own?

Before learning grammar, please make sure to have learned the tones before, with that being said have fun learning.
